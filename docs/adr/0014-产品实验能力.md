# 0014 产品实验能力

- 状态：已批准
- 日期：2026-11-26

## 背景

提示词、音色、播报风格、费率展示需要对照实验；原方案只有配置灰度分桶。

## 决策

实验定义入 `config/experiments.yaml`；独立盐值分桶；分配写入任务；指标从无内容诊断事件与任务元数据聚合。

## 备选方案与不选的理由

用灰度代替实验：与发布风险控制混用，结论不可信。

## 后果（正面、负面、需要跟进的事项）

正面：迭代有数据依据。负面：诊断数据在欧盟、英国默认关闭，样本量受同意率影响。
