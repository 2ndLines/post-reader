# 0011 国内区 Redis 使用开源版 7.0

- 状态：已批准
- 日期：2026-11-26

## 背景

原方案为 Tair，需预发验证与 BullMQ 的兼容性，不兼容再换。

## 决策

直接使用阿里云云数据库 Redis 开源版 7.0（社区版协议）承载队列、Streams、限流与缓存；代码只用 Redis 7.0 社区版命令集。

## 备选方案与不选的理由

Tair：专有引擎兼容性需事后验证，存在返工。

## 后果（正面、负面、需要跟进的事项）

正面：两区命令集一致，无需「验证后再换」。
