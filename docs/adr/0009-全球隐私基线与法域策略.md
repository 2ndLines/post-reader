# 0009 全球隐私基线与法域策略

- 状态：已批准
- 日期：2026-11-26

## 背景

海外包覆盖多个法域（欧盟、英国、加州等），各自的数据保护法要求不同。

## 决策

一个安装包、一套后端；以 GDPR 级别为全球基线；差异写成 `config/privacy/<jurisdiction>.yaml` 法域策略（同意方式、诊断默认值、权利请求时限、最低年龄、政策附录、当地代表），按店面映射法域，经 `GET /me` 下发；同意记录只追加。

## 备选方案与不选的理由

按法律发布不同版本：维护成本高、易遗漏。

## 后果（正面、负面、需要跟进的事项）

正面：新开放市场只需新增策略。负面：需维护政策附录与当地代表。跟进：主 PRD U10、U23。

## 影响的文档与代码

主 PRD 9.4、9.7、13 U10、U23；iOS PRD IOS-PRIV-02、08；02 §21、§22.6；01 §24.2；后台 ADM-SYS-04
