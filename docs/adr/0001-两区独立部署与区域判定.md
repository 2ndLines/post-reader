# 0001 两区独立部署与区域判定

- 状态：已批准
- 日期：2026-11-26

## 背景

国内外对数据驻留、日志留存与内容审核的要求冲突；两区账户不互通，服务端无法得知某个 Apple ID 是否已在另一区注册。

## 决策

国内区与海外区物理隔离、各自一套账户库；国内包只上架中国大陆店面，海外包上架其余店面；登录时上报 App Store 店面，与安装包区域不符返回 `REGION_MISMATCH`，读不到店面不拦截；两区不交换任何账户标识。

## 备选方案与不选的理由

跨区查询账户是否已注册：需要两区交换账户标识摘要，属于跨境数据传输，不选。

## 后果（正面、负面、需要跟进的事项）

正面：两区数据完全隔离，合规边界清楚。负面：同一 Apple ID 在两区是两个账户，订阅不互通，需客服统一口径。跟进：主 PRD U14 由合规负责人确认。

## 影响的文档与代码

主 PRD 9.3、13 U14；iOS PRD IOS-AUTH-04；00 §3.1；02 §4.2、§21；01 §8.1；`config/regions.yaml`
