# 0003 两区合成标识与自嵌统一水印

- 状态：已批准（水印方案为默认，待合规确认 U21）
- 日期：2026-11-26

## 背景

国内《人工智能生成合成内容标识办法》要求显式与隐式标识；欧盟 AI 法案第 50 条要求机器可读、可检测的标记。部分厂商自带水印（如 Google Gemini TTS、ElevenLabs 使用 SynthID），但主备厂商不一致，且只能用各自厂商的工具检测。

## 决策

两区相同处理：开场提示音作为显式标识；元数据隐式标识（国内按国家标准字段，海外按 C2PA）；自嵌统一水印（开源 AudioSeal，ONNX 运行于 `audio-worker`，限幅之后、编码之前嵌入）；保留厂商自带水印作为补充，不作为合规依据。

## 备选方案与不选的理由

只依赖厂商水印：覆盖不全、不可统一检测。云端水印服务（异步任务接口）：增加首段延迟，不适合流式切片。

## 后果（正面、负面、需要跟进的事项）

正面：检测口径统一、自主可控。负面：每切片增加 CPU 开销。跟进：容量规划与 G15 计入水印开销；许可证登记。

## 影响的文档与代码

主 PRD 9.3、13 U21；02 §8.2、§22.3；04 G10；05 §11
