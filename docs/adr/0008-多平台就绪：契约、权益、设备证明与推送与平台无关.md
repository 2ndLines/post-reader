# 0008 多平台就绪：契约、权益、设备证明与推送与平台无关

- 状态：已批准
- 日期：2026-11-26

## 背景

预期接入 Android 或 Web。

## 决策

契约与错误码平台无关（`Platform`）；订阅权益层与商店解耦（`StoreProvider`：apple / google / web，表 `entitlements`）；设备证明抽象为 `AttestProvider`（app_attest / play_integrity / web_risk）；推送令牌接口与通知事件模型从第一版上线（iOS 本期不申请权限）；客户端在 `hello` 中声明能力。

## 备选方案与不选的理由

按 iOS 专有实现、以后再抽象：接入新平台时要改协议与账本，属于返工。

## 后果（正面、负面、需要跟进的事项）

正面：接入新平台只需新增适配器。负面：第一版多几张表与接口。跟进：主 PRD U1、U22。
