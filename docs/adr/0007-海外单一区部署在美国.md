# 0007 海外单一区部署在美国

- 状态：已批准
- 日期：2026-11-26

## 背景

Apple 在中国大陆以外有 174 个店面，一个海外包可覆盖全部；需要决定海外后端的部署位置与区数。

## 决策

海外只设一个区，部署在美国；欧盟 / 欧洲经济区、英国用户的数据出境依据欧美数据隐私框架（DPF）与标准合同条款（SCC），在隐私政策附录告知；不设海外区间迁移；首发上架的店面另定，每开放一个店面先确认其法域策略。

## 备选方案与不选的理由

放欧盟：北美延迟较高。欧盟 + 美国双区：运维与成本翻倍，且需区间迁移能力。

## 后果（正面、负面、需要跟进的事项）

正面：一套海外环境，延迟由边缘分发弥补。负面：依赖 DPF / SCC 的有效性。
