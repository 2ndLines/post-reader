## 2. 产品定位与设计原则

### 2.1 定位
iOS App 是用户接触本产品的唯一界面：把用户分享或粘贴的帖子变成可盲听的音频节目，同时承担本机采集、校验、离线兜底与隐私保护。

### 2.2 设计原则
1. **先登录，再一切**：没有访客模式；未登录时分享来的链接不抓取、不入队（主 PRD 7.1）。
2. **内容只在本机**：帖子内容、站点凭证、播放记录都只在本机加密保存；上报给服务端的诊断数据只含白名单字段（主 PRD 9.1、9.4）。
3. **每一种失败都有下一步**：任何失败状态都告诉用户发生了什么、还能做什么（重试、去登录站点、查看原文、改用本机朗读）。
4. **断网也能听**：已缓存内容、本机语音朗读与离线翻译在无网时可用（主 PRD 10.2）。
5. **盲操优先**：播放相关的核心操作都能通过耳机线控、锁屏与 CarPlay 完成（主 PRD 8.4）。
6. **不展示计数**：任何界面都不显示点赞、收藏、浏览、热度或排名（主 PRD 7.3）。

### 2.3 目标
| 目标 | 衡量方式 |
| :--- | :--- |
| 首段播报快 | 冷启动同语种 TTFA P95 ≤ 1.5 s；跨语种 ≤ 2.8 s 且 0.5 s 内有等待音；缓存直读 ≤ 300 ms（主 PRD 10.1） |
| 听得完 | 有效收听完播率 ≥ 68%（主 PRD 2.2，口径见 2.2 指标口径） |
| 后台不被杀 | 后台播放常驻内存 ≤ $M_{\text{bg\_ram}}$；本地总占用 ≤ $D_{\text{total}}$（主 PRD 10.3） |
| 失败可恢复 | 第 6 节每个提示都给出可执行的下一步；采集失败后用户能自助恢复的比例可在诊断数据中统计 |

## 4. 信息架构

```text
启动
├─ 介绍页 → 欢迎页（Sign in with Apple / 邮箱）→ 邮箱登录（邮箱 + 验证码同屏）
└─ 首页（推荐 / 收藏）
   ├─ 顶部：粘贴链接、扫码添加、搜索（底部弹层）、通知（底部弹层）、设置
   ├─ 帖子卡片 → 更多菜单（加入播放列表 / 接下来播放 / 查看原文 / 立即播放 / 删除〔仅收藏〕）
   ├─ 迷你播放条 → 播放页
   │   ├─ 播放列表（底部弹层，半屏 / 全屏）
   │   ├─ 原文视图（原文、评论、译文对照）
   │   └─ 更多：收藏、朗读译文 / 原文、投诉此内容〔国内〕
   └─ 设置
       ├─ 账号：登录方式、退出登录
       ├─ 订阅与配额：当前档位、本期剩余、恢复时间、订阅页、管理订阅、恢复购买
       ├─ 语言与偏好：目标语言、免译语言、信息密度、播报风格、选拔加权
       ├─ 站点登录：已登录站点列表 → 单站点页（状态、退出登录）
       ├─ 隐私：锁屏隐私模式、共享诊断数据、导出我的数据、一键清理
       ├─ 帮助与反馈：支持码、联系客服、投诉举报〔国内〕、我的投诉〔国内〕
       ├─ 关于：版本、模型与备案公示〔国内〕、隐私政策、用户协议、开源许可
       └─ 注销账号
系统入口：共享扩展、锁屏与控制中心、耳机线控、CarPlay
```

「订阅与配额」即主 PRD 11.4 所说的「我的」页。

## 5. 功能需求
级别：**必须** = 首个上架版本必须具备；**应** = 首个版本尽量具备，可延后一个版本。

### 5.1 启动、登录与区域（AUTH）
| 编号 | 需求 | 级别 |
| :--- | :--- | :--- |
| IOS-AUTH-01 | 首次启动依次展示介绍页、欢迎页；未完成登录不得进入主界面，也不能试听样帖（主 PRD 7.1）。 | 必须 |
| IOS-AUTH-02 | 欢迎页提供 Sign in with Apple 与邮箱两个入口，并说明产品依赖账户级云端配额账本与加密同步（主 PRD 7.1）。 | 必须 |
| IOS-AUTH-03 | 邮箱登录为单屏：邮箱与 6 位验证码同屏；发送后 $T_{\text{otp}}$ 倒计时内不可重发；支持系统验证码自动填充；验证码错误、过期、发送过频分别提示（主 PRD 7.3）。 | 必须 |
| IOS-AUTH-04 | 登录成功即绑定账户归属区（由安装包所属区域决定），不提供跨区登录（主 PRD 9.3）。登录请求携带 App Store 店面国家或地区；服务端判定与本包区域不符（判定依据见主 PRD 9.3、13 U14）时返回区域不匹配，弹出对话框：<br>**标题**：账号区域不匹配<br>**内容**：您的账号注册于其他国家/地区，请前往App Store下载对应版本或创建新账号。<br>**按钮**：「前往 App Store」打开另一区域版本的 App Store 页面；「创建新账号」回到欢迎页（用户可在系统设置中切换到本区的 Apple 账户后重新登录）。对话框关闭后停留在欢迎页，不进入主界面。 | 必须 |
| IOS-AUTH-05 | 会话过期时静默续期；续期失败（例如会话已被吊销）视同退出登录：执行 5.14 的退出登录清理，回到欢迎页并提示「登录已失效，请重新登录」。 | 必须 |
| IOS-AUTH-06 | **首次启动清理**：每次全新安装（含卸载后重装）的首次启动，先清除钥匙串中本 App 遗留的全部条目（登录令牌、站点凭证、数据库与音频密钥），再进入介绍页。用户删除 App 后，其站点登录不应在重装后复活（评审 §8 IF2）。 | 必须 |
| IOS-AUTH-07 | **审核演示账号**：App Store 审核员使用指定的演示邮箱登录；该邮箱的验证码由服务端按配置固定，只在生产区对该邮箱生效，限频且每次使用都记入审计；演示账号为独立账户，不含任何真实用户数据，额度足够完成审核（评审 §8 IF14）。 | 必须 |
| IOS-AUTH-08 | **年龄确认**：欢迎页的登录入口下方显示「我已年满 18 岁」勾选项，未勾选时 Sign in with Apple 与邮箱入口都不可用；勾选结果随首次登录上报并记录。App Store 年龄分级按 18+ 申报（主 PRD 7.1、13 U23、U26）。 | 必须 |

| IOS-HOME-05 | 粘贴链接使用系统粘贴控件，不轮询剪贴板；粘贴后先校验链接；校验通过后弹出操作选项：<br>1. **立即播放**：插入到播放列表中当前帖的位置并立即采集、起播；被打断的当前帖保存进度后顺移为下一篇，播完新帖后从断点续播（与卡片「更多」菜单的「立即播放」同一语义）；没有正在播放的帖子时插入列表首位；<br>2. **接下来播放**：插入当前帖之后；<br>3. **加入播放列表**：追加到末尾。<br>另有系统默认的「取消」，选择后不入队。选择「立即播放」视同用户点击该帖发起播放，剩余额度 ≤ 0 时按主 PRD 11.3 弹出拦截层；另两项只入队，不起播、不触发拦截。校验不通过时不弹出选项，直接提示「不支持的链接」（主 PRD 7.1、11.3）。同一链接已在队列中时提示「已在播放列表中」。 | 必须 |

## 9. 验收门禁
以下各项必须全部满足方可提交审核。标注 [Gx] 的条目由 iOS 测试执行，结果按《测试台架 PRD》TB-GATE-07 导入台架。

1. **凭证不落盘 [G4]**：扫描 App 沙盒与 App Group，第三方站点凭证出现在钥匙串以外位置的次数 = 0；崩溃报告与日志中出现 URL、正文、Cookie、邮箱的次数 = 0。
2. **配额拦截 [G7]**：主 PRD 12.7 的客户端部分逐项通过（拦截层出现率、样帖与缓存不拦截、本机朗读可用性、升级回流、`Pro` 无升级项）。
3. **站点规则回归 [G9]**：站点规则在 HTML 快照样本上的提取结果、回复关系与摘要一致率 = 100%。
4. **响度衔接 [G11]**：本机提示音、本机语音与云端切片衔接处的响度差在允许偏差内。
5. **离线兜底 [G12]**：无网与云端全线故障时，按 IOS-OFF-01、IOS-OFF-02 的决策路径通过率 = 100%；外文帖无语言包时强读次数 = 0。
6. **资源 [G16]**：后台播放常驻内存 ≤ $M_{\text{bg\_ram}}$；共享扩展峰值 < 15 MB；本地总占用 ≤ $D_{\text{total}}$；音频缓存 ≤ 100 MB。
7. **登录门禁**：未登录进入主界面或试听样帖的成功次数 = 0；未登录分享的链接被抓取或入队的次数 = 0；放弃登录后该意图被丢弃的比例 = 100%。
8. **重装清理**：卸载重装后首次启动，钥匙串中遗留的本 App 条目数 = 0。
9. **完整性处理**：注入不一致摘要时，跳过单元、提示、超过 $N_{\text{integrity\_stop}}$ 停止该帖、上报完整性事件的比例 = 100%。
10. **诊断白名单**：抓包检查诊断上报请求，白名单外字段出现次数 = 0；关闭开关后诊断事件（完整性事件除外）上报次数 = 0。
11. **强制升级**：模拟版本过旧时，升级弹窗出现率 = 100%；通过任何手势或按钮关闭弹窗的成功次数 = 0；重新启动与回到前台后再次弹出率 = 100%；弹出后播放暂停，锁屏、耳机、CarPlay 播放指令生效次数 = 0。
12. **审核演示账号**：在生产区用演示邮箱与固定验证码完成登录、样帖播放、粘贴公开链接并播放、订阅沙盒购买与恢复、注销演示账号外的全部审核路径。
13. **扫码与切篇**：扫码识别出链接后的操作与粘贴一致率 = 100%；拒绝相机权限后再次点按出现前往设置的比例 = 100%；播放页上一篇 / 下一篇按播放列表顺序切换，首位时上一篇置灰；配额为 0 时切到需新合成的帖子弹出拦截层的比例 = 100%。
14. **无障碍**：VoiceOver 下完成登录、播放、跳章、收藏、打开设置；最大无障碍字号下核心页面不截断；开启「降低透明度」后悬浮控件为实色。

16. **法域策略**：模拟欧盟、英国店面时诊断开关默认关闭的比例 = 100%；其他店面按策略默认值；同意前诊断事件上报次数 = 0。
