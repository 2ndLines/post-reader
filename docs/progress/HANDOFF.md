# 交接摘要：设计阶段（2026-11-22 至 2026-11-26）

本文是设计阶段对话的交接摘要，供新的开发会话（Claude Code 或其他 AI 编程助手）快速接手。对话本身不随仓库迁移；凡是对话中形成的结论，都已写入下列文档，本文只做索引与提要。**文档与本文冲突时，以文档为准；文档之间冲突时，按 `docs/archs/ai-dev-playbook.md` §0 的优先级处理。**

## 1. 项目一句话

Post&Comments Reader：用户把社交平台帖子链接分享、粘贴或扫码给 App，App 在端侧采集正文与评论，云端编排为多人播报节目（选拔、排序、串场、可选翻译），用多音色语音合成后流式播放。国内与海外两套完全独立的部署。首期交付 iOS；预期接入 Android 或 Web。

## 2. 负责人确定的工作原则

1. **杜绝临时方案与「以后再换」**。技术链路、协议、数据模型、存储与部署形态按业务的长期形态一次选对；功能范围可以分期，但扩展点从第一版起预留。（《业务闭环评审》§11）
2. **待确认事项未决前一律按默认执行**。每条待确认项都有「未决前的默认」，默认值写入配置，确认后只改配置与文档，结论记入 ADR。（ADR 0004）
3. **文档语言为中文**，表述直接、具体；改动需求或设计时同步更新相关文档并记录版本。
4. 单人公司：负责人同时承担产品负责人与 `owner` 角色；合规负责人另行确认的事项见 §6。

## 4. 关键决策提要

**平台与技术栈**
- iOS：Swift 6 + SwiftUI，部署目标 iOS 18，用 Xcode 27 / iOS 27 SDK 构建；iOS 26+ 强制 Liquid Glass，只用于导航与控制层（ADR 0015）。
- 后端：Node 26 LTS + Fastify 5 + zod + Drizzle；PostgreSQL 18；Redis 7.0 社区版命令集（国内阿里云 Redis 开源版 7.0，ADR 0011；海外 Valkey）；BullMQ；Pulumi。
- 海外区：美国单一区（ADR 0007）；对象存储 Cloudflare R2；边缘层 Cloudflare Workers + Hono，第一天即用框架（ADR 0006）。国内区：阿里云，OSS + CDN。
- 两区独立，账户不互通；区域不匹配按 App Store 店面判定（ADR 0001）。

**音频与协议**
- WebSocket 只传控制消息；音频为签名 URL 下载的 AAC 切片，先校验摘要再播放；不用 SSE、不推音频字节流、不用 HLS（ADR 0005）。
- 按播放位置滚动合成（位置 + 30 s）；第一版协议即含 `chapter.map`、`seek`、`seek.ack`、位置语义 `progress`；单篇上限相关的 `job.capped`、`job.truncated`、`extend`（00 §3.1）。

**计费**
- 统一额度池，以「点」计量；底层按各厂商实际计价口径记录原始用量与分渠道成本，用户侧按参数化费率系数实时折算、同一事务原子核销；主备渠道折算差异 ≤ 10%（ADR 0002）。
- 费率系数与单篇上限开发期用默认值，正式数值由测试台架计费标定套件测算、负责人审阅后生效（ADR 0016）。

**合规与隐私**
- 两区合成标识相同：显式提示音 + 元数据隐式标识（国内国标字段、海外 C2PA）+ 自嵌 AudioSeal 水印，保留厂商水印作补充（ADR 0003，待合规确认）。
- 两区都做出声前安全检查（ADR 0010）。
- 全球隐私基线（GDPR 级别）+ 法域策略配置；欧盟、英国诊断数据默认关闭（ADR 0009）。
- 本期不评估采集与合成第三方内容的合法性（主 PRD 1 范围外 3a）。
- 只面向 18 岁及以上；App Store 18+（主 PRD 7.1）。

**多平台与运营**
- 契约、订阅权益（`StoreProvider`）、设备证明（`AttestProvider`）、推送令牌与通知模型平台无关（ADR 0008）。
- 后台审批策略可配置（ADR 0013）；实验能力从第一版具备（ADR 0014）；自然度评分双轨（ADR 0012）。

**已定的交互细节**（iOS PRD 中可查）：强制升级弹窗常驻不可关闭；倍速 0.75 / 1.0 / 1.25 / 1.5 / 2.0；区域不匹配对话框文案；粘贴或扫码后弹出「立即播放 / 接下来播放 / 加入播放列表」；播放页上一篇 / 下一篇；耳机与 CarPlay 的上一首 / 下一首对应帖内章节。
